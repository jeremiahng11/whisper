`mn7_en.srm` - Espressif MultiNet7 English speech-command model (the `mn7_en` part of ESP-SR's `srmodels.bin`,
from esp-sr in the Arduino-ESP32 3.3 libraries; ESPRESSIF MIT License: for use with Espressif chips). The Idea Saver
Round downloads it once (`GET /api/watch/speech`) to hear the answer pack's questions offline.
