`srmodels.bin` - Espressif ESP-SR speech models exactly as shipped with the Arduino-ESP32 3.3 libraries
(MultiNet7 English, VADNet, the FST command files and WakeNet9 "Hi ESP"; ESPRESSIF MIT License: for use with
Espressif chips). The Idea Saver Round downloads it once (`GET /api/watch/speech`) to hear the answer pack's
questions offline. (1.12-1.13.0 sent only the MultiNet part; that copy crashed the watch.)
